IBE Barcode Generator — Help

A free, open-source barcode label generator. This page covers every feature in the current Desktop and Web applications.

The diagrams on this page are simple original schematics of the window layout, not photographic screenshots — the boxes and labels describe where each control lives, not its exact pixel appearance.

Overview

IBE Barcode Generator creates barcode label images from a value you type in, previews them live, and can export a full sheet of labels — including a sequentially-numbered batch of up to 1000 — as a ready-to-print PDF. It supports twenty barcode formats, from simple 1-D formats like Code 39 through 2-D formats like QR Code and Data Matrix.

Quick start

  1. Pick a barcode format from the Symbology dropdown.
  2. Type the value you want encoded into the Barcode Value box. The preview updates as you type.
  3. Optionally fill in User Field 1 (a caption above the barcode) and User Field 2 (a caption below it).
  4. Pick a Current Paper Type matching the label sheets you'll print on.
  5. Use Save Label Sheet PDF... to export a print-ready PDF.

Window layout

The window's height auto-fits its content, so a taller barcode or a higher zoom level never gets clipped at the bottom.

Language

The interface is available in English, 简体中文 (Simplified Chinese), 繁體中文 (Traditional Chinese) and 日本語 (Japanese). Everything the application itself draws — captions, menu items, buttons, the status bar and error messages — follows the chosen language. Text you type, the barcode's own human-readable value, the User Field captions and the paper template names are data, not interface text, so they stay exactly as you entered or chose them.

WhereHow to change it
DesktopLanguage in the menu bar, then pick a language. The choice applies to the current session.
WebThe Language dropdown above the preview. The browser remembers the choice for next time.

Until you choose, the application matches the operating system (Desktop) or the browser's preferred languages (Web), falling back to English when none of the four is asked for. In the Web app you can also force a language with the address: ?lang=ja, ?lang=zh-Hans or ?lang=zh-Hant.

Choosing a symbology

The Symbology dropdown (top toolbar row) selects which barcode format the value is encoded with. Switching formats re-encodes the current value immediately. If the current value isn't valid for the newly-selected format (for example, letters in a numeric-only format like EAN-13), an error message appears above the preview explaining what's wrong.

Font controls

The font row controls the typeface, size, and style used for all text on the label: the barcode's own human-readable value text, and both User Field captions. They always render at a matching size so the label looks consistent.

ControlEffect
Font familyArial, Times New Roman, Courier New, Verdana, or Consolas.
SizePoint size for all label text (6–72).
B / I / UBold, italic, and underline toggles, applied uniformly.

Barcode value, increment & quantity

Barcode Value

The text box next to the Barcode Value checkbox is the value that gets encoded. Unchecking the box hides the human-readable text printed under the bars — the bars themselves are unaffected.

Barcode Increment & Quantity

These two controls generate a batch of sequential labels for Save Label Sheet PDF: Quantity sets how many labels to generate (1–1000), and Barcode Increment sets how much the value's trailing run of digits increases between copies. For example, with value 34738 and increment 1, a quantity of 3 produces 34738, 34739, 34740 on successive labels. If the value has no trailing digits, the increment has nothing to act on and every copy stays identical.

Increment and Quantity only affect the exported PDF, not the live on-screen preview (which always shows the first label in the batch).

User Field 1 & 2

Two optional captions printed as part of the label image, independent of the barcode's own value text:

FieldPositionIncrement
User Field 1Above the barcodeNo — always printed as typed.
User Field 2Below the barcode's value textYes, via User Field 2 Increment, using the same trailing-digit rule as Barcode Increment.

Paper template

Current Paper Type selects which physical label sheet layout to print onto — this determines label size, how many labels fit per sheet, and their position on the page. It includes several Avery layouts (5160, 5161, 5162, 5163, 5164, 5167 at the time of writing); each was verified to exactly fit a US Letter page before being added.

Rotate & zoom

Rotate Left / Rotate Right spin the label image in 90° steps (0°, 90°, 180°, 270°) — available from the toolbar and the Tools menu.

Zoom In / Zoom Out change how large the preview appears on screen in 25% steps; this is purely a display setting and never affects the exported PDF's physical size.

Exporting a label sheet PDF

Save Label Sheet PDF... (File menu or toolbar) renders the current label — or, if Quantity is greater than 1, the whole sequential batch — onto the selected paper template and writes a PDF you're prompted to save. A batch larger than one sheet's worth of labels automatically continues onto additional pages, so a 1000-label run on a 30-label sheet produces 34 pages.

Status bar

The bar along the bottom of the window shows, left to right: the current zoom percentage, the selected paper template's label size, the current symbology name, and today's date.

Supported barcode formats

FormatWhat it's typically used for
Code 39General-purpose alphanumeric barcode; widely supported by low-cost scanners.
Extended Code 39Code 39 variant that adds lowercase letters and punctuation via character pairs.
Interleaved 2 of 5Compact numeric-only barcode, common in warehousing and shipping.
CodabarNumeric barcode with selectable start/stop characters; historically used in libraries and blood banks.
Code 93Denser successor to Code 39 with built-in checksums.
Code 128 (auto subset)High-density alphanumeric barcode covering the full ASCII range; automatically switches between its internal character subsets for compact encoding.
GS1-128Code 128 carrying GS1 Application Identifier data (e.g. batch numbers, dates, quantities) in a standardized element-string notation.
EAN-13 / EAN-8International retail product barcodes.
UPC-A / UPC-ENorth American retail product barcodes; UPC-E is a zero-suppressed, more compact form of UPC-A.
UPC 2-digit / 5-digit supplementSmall add-on barcodes printed alongside UPC/EAN codes, typically for periodical issue numbers or suggested retail price.
ISBNBook identifier barcode (an EAN-13 variant with the 978/979 Bookland prefix).
PostnetUSPS height-modulated barcode encoding a ZIP code.
QR Code2-D matrix barcode; auto-selects the most compact internal mode (numeric, alphanumeric, byte, or Kanji) for the given value.
Data MatrixCompact 2-D matrix barcode used widely in electronics and small-item marking.
PDF417High-capacity stacked 2-D barcode, used on ID cards, boarding passes, and shipping labels.
Aztec Code2-D matrix barcode that needs no surrounding quiet zone, used on transit and boarding tickets.

Web vs. Desktop

The Web app mirrors the Desktop app's preview and PDF export features and runs entirely in your browser — no data is sent to a server. The Desktop app additionally integrates with your operating system's native file save dialog.

Troubleshooting

MessageWhat it means
"Enter a value to encode."The Barcode Value box is empty.
"Character '…' is outside the … range this encoder supports."The value contains a character the selected format can't represent — try a different symbology, or remove the character.
"Value is too large to encode…"The value is too long for the selected format's maximum capacity.
"Select a paper template before exporting…"No paper type is selected in the Current Paper Type dropdown.
