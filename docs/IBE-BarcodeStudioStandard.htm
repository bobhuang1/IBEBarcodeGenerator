IBE Barcode Studio Standard Edition

      - Complete Barcode Printing Solution
Sunrise 2005 Compliant!

IBE Barcode Studio Standard Edition is the easy-to-use program that lets anyone generate great barcode images in seconds, on any Windows-compatible printer! Batch print of same/sequential barcode enabled!

IBE Barcode Studio Standard Edition includes many advanced features, such as:
Thirteen formats of Barcode: Code 39, Extended Code 39, Interleaved 2 of 5, Codabar, Code 128, EAN-13, EAN-8, UCC/EAN 128, UPC-A, UPC-E, UPC 2, UPC 5 and Postnet
Two user-definable fields on the same Barcode: that allows you to manage their items more effectively
Auto-Increment on the Barcode and the second user field: that allows you to create Barcodes in sequential numbers easily
Print multiple labels: you can print up 1,000 sequential barcode labels
Zoom In/Zoom out functions: you can view the Barcode in detail
Barcode rotation: entire Barcode can be rotated 90, 180, 270 degrees
Broad export support: Entire Barcode label can be exported to other images
formats such as BMP, GIF, JPG and TIF. It can also be copied to the Windows clipboard to allow other applications to use the Barcode.
Paper Template Support: Supports more than 1,000 label paper templates (including Aone, APLI, Avery, Devauzet, ERO, Formtec, Herma, Hisago, Kokuyo, MACO, Pimaco, Rank Xerox, Zweckform), you can also define your own paper templates.

 Minimum System Requirements:
CPU: Requires at least a Pentium (or better) PC running Microsoft Windows 98SE, Windows Me, Windows 2000, Windows XP, or Windows 2003 or later. Windows 2000 and above operating systems are recommended.
Printer: To print a quality Barcode, you need a dot matrix/ink jet/thermal/laser printer. For best quality and cost savings, we recommend you to use a laser printer to print Barcode images.
Hard Drive Space: To download and install IBE Barcode Studio Standard Edition on your PC, you need at least 30 megabytes of free space.
