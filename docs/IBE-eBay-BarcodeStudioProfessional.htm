IBE Barcode Studio Professional Edition

      - Complete Professional Barcode Printing Solution for High-Volume Users
Sunrise 2005 Compliant!

IBE Barcode Studio Professional Edition is the easy-to-use program that lets anyone generate great barcode images in seconds, on any Windows-compatible printer! Batch print of same/sequential barcode enabled!

IBE Barcode Studio Professional Edition includes many advanced features, such as:
Sixteen formats of Barcode: Code 93, MSI Plessey, ISBN, Code 39, Extended Code 39, Interleaved 2 of 5, Codabar, Code 128, EAN-13, EAN-8, UCC/EAN 128, UPC-A, UPC-E, UPC 2, UPC 5 and Postnet
Spreadsheet-like barcode designer
Mix and match and combine barcode labels to print on a single paper - save the environment!
Define the location (row and column) to print on the paper
Two user-definable fields on the same Barcode: that allows you to manage their items more effectively
Auto-Increment on the Barcode field: that allows you to create Barcodes in incremental numbers easily
Broad export support: Entire Barcode label can be exported to other images
formats such as BMP, GIF, JPG and TIF. It can also be copied to the Windows clipboard to allow other applications to use the Barcode.
Paper Template Support: Supports more than 1,000 label paper templates (including Aone, APLI, Avery, Devauzet, ERO, Formtec, Herma, Hisago, Kokuyo, MACO, Pimaco, Rank Xerox, Zweckform), you can also define your own paper templates.
