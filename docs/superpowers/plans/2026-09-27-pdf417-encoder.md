# PDF417 Encoder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a from-scratch PDF417 encoder — a stacked linear 2D format widely used for IDs, shipping labels, and boarding passes.

**Scope decision (deliberate, mirroring the QR and Data Matrix plans):**
- **Byte Compaction mode only** — no Text Compaction, no Numeric Compaction, no multi-mode switching mid-message. Byte Compaction handles any byte sequence uniformly (it's the format's general-purpose fallback mode), so this alone gives full functional coverage at the cost of slightly larger symbols than a mode-optimized encoder would produce for pure-text or pure-numeric input. Input is restricted to bytes 0-255 (`(byte)char` cast, reject anything above `ÿ`) — this is Latin-1/raw-byte semantics, not UTF-8, avoiding multi-byte encoding ambiguity.
- **Standard (non-compact) PDF417 only** — always emits the right row-indicator codeword and the full 18-bit stop pattern. "Compact/Truncated PDF417" (an ISO-defined space-saving variant that drops these) is not implemented.
- **Error correction levels 0-5 only** (2/4/8/16/32/64 codewords). ISO 15438 Annex E's own recommended-minimum-level table never recommends level 6, 7, or 8 for any data size up to the format's practical ~863-data-codeword ceiling — those levels exist purely as optional extra-strength choices backed by very large (128/256/512-entry) coefficient tables. Skipping them avoids transcribing untested-scope data. The encoder auto-selects the ISO-recommended minimum level from the actual data size (levels 0-1 are never "recommended minimum" by that table either, so the effective auto-selected range is 2-5), matching `IMatrixBarcodeEncoder`'s single-parameter `TryEncode(string)` signature (no separate error-correction-level parameter).
- **No ECI / character set switching** — output is always the default byte-oriented encoding, matching the Byte-Compaction-only scope above.

**Architecture:** PDF417's symbol structure — each of the format's 17-module-wide "codeword patterns" is really just 17 individual 1-bit-wide modules read MSB-first — turns out to be exactly `BarcodeMatrix`'s shape (a uniform bool grid), not `BarcodePattern`'s (variable-width bar segments) despite PDF417 usually being described as a "stacked linear" format. This plan reuses `BarcodeMatrix`/`IMatrixBarcodeEncoder`/`MatrixRenderer` unchanged — the same abstraction QR and Data Matrix use — rather than inventing a new one. Total symbol width in modules is exactly `17 * cols + 69` (17 start + 17 left-indicator + 17*cols data + 17 right-indicator + 18 stop), which is also the literal constant ZXing's own row-sizing heuristic uses — a useful independent cross-check that this plan's width accounting matches the source it was verified against.

Files: `Pdf417CodewordTable` (the 3×929 codeword-to-module-pattern table), `Pdf417ErrorCorrectionCoefficients` (levels 0-5), `Pdf417ErrorCorrection` (GF(929) prime-field error correction — simple integer arithmetic mod 929, no Galois exp/log tables needed, unlike QR/Data Matrix's GF(256)), `Pdf417HighLevelEncoder` (Byte-Compaction-only data encoding), `Pdf417Encoder` (orchestrates dimension selection, padding, error correction, and module placement into a `BarcodeMatrix`).

**Tech Stack:** .NET 10, xUnit. Every structural piece was fetched as complete, literal source from ZXing's `pdf417.encoder` package (`PDF417.java`, `PDF417ErrorCorrection.java`, `PDF417HighLevelEncoder.java`) — Apache 2.0, itself sourced from ISO/IEC 15438:2001(E). **The codeword table (2,787 hex values) and the error-correction coefficient tables were extracted mechanically with a script** (byte-for-byte from the fetched source, brace-counted and length-asserted against the known table shape: 3×929, and 2/4/8/16/32/64/128/256/512 per level respectively — all 9 levels' lengths verified even though only 0-5 are kept) rather than hand-retyped, specifically because hand-transcribing thousands of hex/decimal values reliably is impractical and error-prone. The resulting generated `.cs` files are committed as ordinary source (do not hand-edit; regenerate from source if ever needed) and are referenced by this plan rather than reproduced inline. This is a deliberate, documented exception to this plan's own "no placeholders, full literal code" rule for large mechanically-verified data tables specifically — every other file in this plan contains complete, literal, hand-reviewed code as usual.

## Verified reference values used by this plan

- `START_PATTERN = 0x1fea8` (17 bits), `STOP_PATTERN = 0x3fa29` (18 bits) — fixed, from ISO Annex A.
- `Pdf417CodewordTable.Patterns[cluster][codeword]` — 3 clusters (representing row `y % 3`), 929 codewords each, a 17-bit module pattern per codeword. Mechanically extracted (see above), verified length 3×929=2787.
- `Pdf417ErrorCorrectionCoefficients.Levels[level]` — levels 0-5, lengths 2/4/8/16/32/64. Mechanically extracted, verified against all 9 source levels' lengths before scoping down.
- Error-correction-codeword count for level `L`: `1 << (L + 1)`.
- ISO Annex E recommended minimum level by data-codeword count `n`: `n<=40`→2, `n<=160`→3, `n<=320`→4, `n<=863`→5 (levels 0-1 never recommended; this plan's auto-selection uses this table directly, so it always picks 2-5).
- Row-count formula (Annex Q): `r = (m + 1 + k) / c + 1`, then `r--` if `c*r >= m+1+k+c`, where `m`=source codewords, `k`=EC codewords, `c`=columns.
- Pad-codeword count (4.9.2): `n = c*r - k`; pad = `n > m+1 ? n-m-1 : 0`.
- Dimension search (Annex Q, simplified — this plan fixes `minCols=2, maxCols=30, minRows=3, maxRows=90` rather than exposing them as parameters, matching `IMatrixBarcodeEncoder`'s single-parameter signature): for each `cols` in range, compute `rows` via the row-count formula; skip if outside `[minRows,maxRows]`; among valid candidates pick the one whose `(17*cols+69)*0.357 / (rows*2.0)` ratio is closest to `3.0` (the format's preferred aspect ratio).
- Byte Compaction encoding (`encodeBinary`, Byte-Compaction-only path): emit latch codeword `924` if `byteCount % 6 == 0`, else `901`; then for each full group of 6 bytes, pack as a 48-bit integer and repeatedly take `% 900` (5 times, reversed) to get 5 codewords; then append any remaining `0-5` leftover bytes as raw codewords (byte value 0-255 each, since Byte Compaction leftover codewords use raw byte values directly, not base-900 packing).
- Symbol Length Descriptor: first data codeword = `sourceCodeWords + pad + 1` (the `+1` counts the descriptor itself).
- Error correction (`generateErrorCorrection`, GF(929), prime field so no log/antilog tables — direct modular arithmetic): for `k` EC codewords and coefficient array `poly` of length `k`, iterate `t1 = (codeword + e[k-1]) % 929` for each data codeword, then for `j` from `k-1` down to `1`: `e[j] = (e[j-1] + (929 - (t1*poly[j])%929)) % 929`; `e[0] = (929 - (t1*poly[0])%929) % 929`. Final EC codewords, in order: for `j` from `k-1` down to `0`, output `e[j]==0 ? 0 : 929-e[j]`.
- Row-indicator codewords (`encodeLowLevel`, cluster = `y % 3`): cluster 0 → left=`30*(y/3) + (r-1)/3`, right=`30*(y/3) + (c-1)`; cluster 1 → left=`30*(y/3) + level*3 + (r-1)%3`, right=`30*(y/3) + (r-1)/3`; cluster 2 → left=`30*(y/3) + (c-1)`, right=`30*(y/3) + level*3 + (r-1)%3`. Row layout: START(17) + left-indicator(17) + data codewords(17 each) + right-indicator(17) + STOP(18).

```csharp
namespace IBEBarcode.Core.Encoders.Pdf417;

internal static class Pdf417ErrorCorrection
{
    public static int[] Generate(int[] dataCodewords, int level)
    {
        var poly = Pdf417ErrorCorrectionCoefficients.Levels[level];
        var k = poly.Length;
        var e = new int[k];

        foreach (var codeword in dataCodewords)
        {
            var t1 = (codeword + e[k - 1]) % 929;

            for (var j = k - 1; j >= 1; j--)
            {
                var t2 = (t1 * poly[j]) % 929;
                var t3 = 929 - t2;
                e[j] = (e[j - 1] + t3) % 929;
            }

            var t2First = (t1 * poly[0]) % 929;
            var t3First = 929 - t2First;
            e[0] = t3First % 929;
        }

        var result = new int[k];

        for (var j = k - 1; j >= 0; j--)
        {
            result[k - 1 - j] = e[j] == 0 ? 0 : 929 - e[j];
        }

        return result;
    }
}
```

```csharp
namespace IBEBarcode.Core.Encoders.Pdf417;

internal static class Pdf417HighLevelEncoder
{
    private const int LatchToBytePadded = 901;
    private const int LatchToByte = 924;

    public static int[] EncodeBytes(byte[] bytes)
    {
        var codewords = new List<int>
        {
            bytes.Length % 6 == 0 ? LatchToByte : LatchToBytePadded,
        };

        var idx = 0;

        while (bytes.Length - idx >= 6)
        {
            long t = 0;

            for (var i = 0; i < 6; i++)
            {
                t <<= 8;
                t += bytes[idx + i];
            }

            var chunk = new int[5];

            for (var i = 0; i < 5; i++)
            {
                chunk[i] = (int)(t % 900);
                t /= 900;
            }

            for (var i = 4; i >= 0; i--)
            {
                codewords.Add(chunk[i]);
            }

            idx += 6;
        }

        for (var i = idx; i < bytes.Length; i++)
        {
            codewords.Add(bytes[i]);
        }

        return codewords.ToArray();
    }
}
```

```csharp
using IBEBarcode.Core;
using IBEBarcode.Core.Encoders;
using IBEBarcode.Core.Encoders.Pdf417;

namespace IBEBarcode.Core.Tests.Encoders;

public class Pdf417RoundTripTests
{
    [Theory]
    [InlineData("Hi")]
    [InlineData("PDF417 test string!")]
    [InlineData("The quick brown fox jumps over the lazy dog 0123456789")]
    public void EncodeThenDecode_RoundTripsExactly(string original)
    {
        var encoder = new Pdf417Encoder();
        var success = encoder.TryEncode(original, out var matrix, out var error);

        Assert.True(success, error);

        var decoded = Decode(matrix!);

        Assert.Equal(original, decoded);
    }

    private static string Decode(BarcodeMatrix matrix)
    {
        var cols = (matrix.Width - 69) / 17;
        var rows = matrix.Height;

        // Build a reverse lookup: pattern -> codeword, per cluster.
        var reverseLookup = new Dictionary<int, int>[3];

        for (var cluster = 0; cluster < 3; cluster++)
        {
            reverseLookup[cluster] = new Dictionary<int, int>();

            for (var codeword = 0; codeword < 929; codeword++)
            {
                reverseLookup[cluster][Pdf417CodewordTable.Patterns[cluster][codeword]] = codeword;
            }
        }

        int ReadPattern(int startCol, int row, int bitCount)
        {
            var pattern = 0;

            for (var i = 0; i < bitCount; i++)
            {
                pattern <<= 1;
                pattern |= matrix[startCol + i, row] ? 1 : 0;
            }

            return pattern;
        }

        var allDataCodewords = new List<int>();

        for (var y = 0; y < rows; y++)
        {
            var cluster = y % 3;
            var col = 17 + 17; // skip START and left row-indicator

            for (var x = 0; x < cols; x++)
            {
                var pattern = ReadPattern(col, y, 17);
                allDataCodewords.Add(reverseLookup[cluster][pattern]);
                col += 17;
            }
        }

        // First codeword is the Symbol Length Descriptor; strip it and any trailing
        // PAD(900)/error-correction codewords by using the descriptor's own count.
        var totalDataAndDescriptor = allDataCodewords[0];
        var sourceAndPad = allDataCodewords.GetRange(1, totalDataAndDescriptor - 1);

        // Strip PAD (900) codewords from the end.
        var lastNonPad = sourceAndPad.Count - 1;

        while (lastNonPad >= 0 && sourceAndPad[lastNonPad] == 900)
        {
            lastNonPad--;
        }

        var highLevel = sourceAndPad.GetRange(0, lastNonPad + 1);

        // highLevel[0] is the Byte Compaction latch (901 or 924); decode the rest.
        var codewordsAfterLatch = highLevel.GetRange(1, highLevel.Count - 1);
        var bytes = new List<byte>();
        var idx = 0;

        while (highLevel.Count - 1 - idx >= 5 && codewordsAfterLatch.Count - idx >= 5)
        {
            long t = 0;

            for (var i = 0; i < 5; i++)
            {
                t = t * 900 + codewordsAfterLatch[idx + i];
            }

            var sixBytes = new byte[6];

            for (var i = 5; i >= 0; i--)
            {
                sixBytes[i] = (byte)(t & 0xff);
                t >>= 8;
            }

            bytes.AddRange(sixBytes);
            idx += 5;
        }

        for (var i = idx; i < codewordsAfterLatch.Count; i++)
        {
            bytes.Add((byte)codewordsAfterLatch[i]);
        }

        var chars = new char[bytes.Count];

        for (var i = 0; i < bytes.Count; i++)
        {
            chars[i] = (char)bytes[i];
        }

        return new string(chars);
    }
}
```

```csharp
using IBEBarcode.Core.Encoders.Pdf417;

namespace IBEBarcode.Core.Encoders;

public sealed class Pdf417Encoder : IMatrixBarcodeEncoder
{
    private const int MinCols = 2;
    private const int MaxCols = 30;
    private const int MinRows = 3;
    private const int MaxRows = 90;
    private const float DefaultModuleWidth = 0.357f;
    private const float Height = 2.0f;
    private const float PreferredRatio = 3.0f;
    private const int StartPattern = 0x1fea8;
    private const int StopPattern = 0x3fa29;

    public BarcodeSymbology Symbology => BarcodeSymbology.Pdf417;

    public bool TryEncode(string value, out BarcodeMatrix? matrix, out string? error)
    {
        matrix = null;

        if (string.IsNullOrEmpty(value))
        {
            error = "Value must not be empty.";
            return false;
        }

        var bytes = new byte[value.Length];

        for (var i = 0; i < value.Length; i++)
        {
            if (value[i] > 255)
            {
                error = $"Character '{value[i]}' is outside the 0-255 byte range this PDF417 encoder supports.";
                return false;
            }

            bytes[i] = (byte)value[i];
        }

        var highLevel = Pdf417HighLevelEncoder.EncodeBytes(bytes);
        var sourceCodeWords = highLevel.Length;

        var level = RecommendedMinimumLevel(sourceCodeWords);

        if (level < 0)
        {
            error = "Value is too large to encode: this PDF417 encoder supports at most 863 source codewords.";
            return false;
        }

        var errorCorrectionCodeWords = 1 << (level + 1);

        if (!TryDetermineDimensions(sourceCodeWords, errorCorrectionCodeWords, out var cols, out var rows))
        {
            error = "Unable to fit message within the supported column/row range.";
            return false;
        }

        var pad = GetNumberOfPadCodewords(sourceCodeWords, errorCorrectionCodeWords, cols, rows);

        if (sourceCodeWords + errorCorrectionCodeWords + 1 > 929)
        {
            error = "Encoded message contains too many codewords.";
            return false;
        }

        var n = sourceCodeWords + pad + 1;
        var dataCodewords = new int[n];
        dataCodewords[0] = n;
        Array.Copy(highLevel, 0, dataCodewords, 1, sourceCodeWords);

        for (var i = 0; i < pad; i++)
        {
            dataCodewords[1 + sourceCodeWords + i] = 900;
        }

        var ecCodewords = Pdf417ErrorCorrection.Generate(dataCodewords, level);

        var fullCodewords = new int[dataCodewords.Length + ecCodewords.Length];
        Array.Copy(dataCodewords, fullCodewords, dataCodewords.Length);
        Array.Copy(ecCodewords, 0, fullCodewords, dataCodewords.Length, ecCodewords.Length);

        var width = 17 * cols + 69;
        var modules = new bool[width, rows];

        var idx = 0;

        for (var y = 0; y < rows; y++)
        {
            var cluster = y % 3;
            var col = 0;

            col = WritePattern(modules, col, y, StartPattern, 17);

            int left;
            int right;

            if (cluster == 0)
            {
                left = (30 * (y / 3)) + ((rows - 1) / 3);
                right = (30 * (y / 3)) + (cols - 1);
            }
            else if (cluster == 1)
            {
                left = (30 * (y / 3)) + (level * 3) + ((rows - 1) % 3);
                right = (30 * (y / 3)) + ((rows - 1) / 3);
            }
            else
            {
                left = (30 * (y / 3)) + (cols - 1);
                right = (30 * (y / 3)) + (level * 3) + ((rows - 1) % 3);
            }

            col = WritePattern(modules, col, y, Pdf417CodewordTable.Patterns[cluster][left], 17);

            for (var x = 0; x < cols; x++)
            {
                col = WritePattern(modules, col, y, Pdf417CodewordTable.Patterns[cluster][fullCodewords[idx]], 17);
                idx++;
            }

            col = WritePattern(modules, col, y, Pdf417CodewordTable.Patterns[cluster][right], 17);
            WritePattern(modules, col, y, StopPattern, 18);
        }

        matrix = BarcodeMatrix.Create(value, modules);
        error = null;
        return true;
    }

    private static int WritePattern(bool[,] modules, int startCol, int row, int pattern, int bitCount)
    {
        for (var i = 0; i < bitCount; i++)
        {
            modules[startCol + i, row] = ((pattern >> (bitCount - 1 - i)) & 1) != 0;
        }

        return startCol + bitCount;
    }

    private static int RecommendedMinimumLevel(int n)
    {
        if (n <= 40)
        {
            return 2;
        }

        if (n <= 160)
        {
            return 3;
        }

        if (n <= 320)
        {
            return 4;
        }

        if (n <= 863)
        {
            return 5;
        }

        return -1;
    }

    private static int CalculateNumberOfRows(int m, int k, int c)
    {
        var r = ((m + 1 + k) / c) + 1;

        if (c * r >= (m + 1 + k + c))
        {
            r--;
        }

        return r;
    }

    private static int GetNumberOfPadCodewords(int m, int k, int c, int r)
    {
        var n = c * r - k;
        return n > m + 1 ? n - m - 1 : 0;
    }

    private static bool TryDetermineDimensions(int sourceCodeWords, int errorCorrectionCodeWords, out int cols, out int rows)
    {
        var ratio = 0.0f;
        var found = false;
        cols = MinCols;
        rows = MinRows;
        var currentCol = MinCols;

        for (var c = MinCols; c <= MaxCols; c++)
        {
            currentCol = c;
            var r = CalculateNumberOfRows(sourceCodeWords, errorCorrectionCodeWords, c);

            if (r < MinRows)
            {
                break;
            }

            if (r > MaxRows)
            {
                continue;
            }

            var newRatio = ((17 * c + 69) * DefaultModuleWidth) / (r * Height);

            if (found && Math.Abs(newRatio - PreferredRatio) > Math.Abs(ratio - PreferredRatio))
            {
                continue;
            }

            ratio = newRatio;
            cols = c;
            rows = r;
            found = true;
        }

        if (!found)
        {
            var r = CalculateNumberOfRows(sourceCodeWords, errorCorrectionCodeWords, currentCol);

            if (r < MinRows)
            {
                cols = MinCols;
                rows = MinRows;
                found = true;
            }
        }

        return found;
    }
}
```
